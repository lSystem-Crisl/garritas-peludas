# 🐾 Garritas Peludas

Sistema web de citas para la veterinaria **Garritas Peludas**.

## 📋 Descripción

Proyecto web desarrollado para facilitar la gestión de citas y brindar información sobre los servicios de la veterinaria.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 📁 Estructura del proyecto

- `css/` → Archivos de estilos.
- `imagen/` → Imágenes utilizadas en el sitio web.
- `js/` → Archivos JavaScript.
- `paginas/` → Páginas secundarias del sitio.
- `índice.html` → Página principal.

## 🎯 Objetivo

Desarrollar un sitio web para la veterinaria Garritas Peludas, permitiendo a los usuarios consultar información y gestionar sus citas.

## 👨‍💻 Proyecto académico

Proyecto desarrollado como parte del curso de Desarrollo Web.
